# KLKOO

## Panel azul para Roblox Studio

La implementación nueva está en [`StudioAdminPanel/`](StudioAdminPanel/README.md). Incluye scripts de servidor y cliente para un panel de desarrollo con Fly, ESP, Speed y High Jump, protegido para el propietario o administradores configurados.

Sigue las instrucciones de instalación en [`StudioAdminPanel/README.md`](StudioAdminPanel/README.md). Estos scripts están pensados para instalarse en tu propia experiencia de Roblox Studio; no son un executor.

`prueba24` es un prototipo anterior que solo imprime mensajes de prueba y no activa habilidades de combate.
